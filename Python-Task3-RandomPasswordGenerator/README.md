# Random Password Generator

## Objective
To create a Python program that generates a strong random password based on the length entered by the user.

## Features
- Takes password length from the user.
- Generates random passwords.
- Uses uppercase and lowercase letters.
- Includes numbers and special characters.
- Handles invalid input.

## Technologies Used
- Python
- Random module
- String module

## How It Works
1. The user enters the required password length.
2. The program creates a collection of letters, numbers, and special characters.
3. Random characters are selected from the collection.
4. The generated password is displayed on the screen.

## Example Output
Generated Password: <7qFmrL!+7El

## Outcome
Successfully created a Python-based Random Password Generator that generates random passwords according to the required length.
